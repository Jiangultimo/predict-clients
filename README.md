# PredictDesk

一个预测市场 AI 工作台前端，面向类似 Polymarket 的事件预测、概率定价和领域权威数字分身分析场景。

## Flow

- Landing：预测市场工作台首屏，进入登录流程。
- Onboarding：对话式冷启动，生成用户预测画像。
- Follow：推荐在特定预测领域有权威的人和他的数字分身，必须关注后才能继续。
- Agents：用户默认拥有全部功能型 Agent，进入 Prediction Room 后在右侧调用。
- Prediction Room：Discord 式预测工作台，数字分身推送相关市场信号并用打字机效果解释动因、变量和风险。
